# Histórias de Usuário — Sistema Mentary

## 1. Professor

**Objetivo:** Gerenciar questões, avaliações e acompanhar a aprendizagem dos estudantes.

- **HU-PROF-01:** Como professor, quero enviar questões para o sistema, para contribuir com o banco de questões.
- **HU-PROF-02:** Como professor, quero revisar minhas questões enviadas, para corrigir erros e melhorar sua qualidade.
- **HU-PROF-03:** Como professor, quero criar avaliações utilizando questões disponíveis, para avaliar o conhecimento dos estudantes.
- **HU-PROF-04:** Como professor, quero aplicar avaliações às minhas turmas, para verificar o desempenho dos estudantes.
- **HU-PROF-05:** Como professor, quero visualizar os resultados das avaliações, para identificar dificuldades de aprendizagem.
- **HU-PROF-06:** Como professor, quero acompanhar o desempenho individual dos estudantes, para identificar necessidades de apoio pedagógico.
- **HU-PROF-07:** Como professor, quero analisar os resultados por habilidade e descritor, para direcionar minhas estratégias de ensino.

## 2. Revisor autorizado

**Objetivo:** Garantir a qualidade e a confiabilidade das questões antes de sua inclusão no banco de questões.

- **HU-REV-01:** Como revisor autorizado, quero visualizar as questões extraídas que aguardam revisão, para iniciar o processo de validação.
- **HU-REV-02:** Como revisor autorizado, quero corrigir erros de texto e formatação nas questões, para garantir sua clareza e legibilidade.
- **HU-REV-03:** Como revisor autorizado, quero verificar os enunciados, as alternativas e os gabaritos, para garantir a consistência das questões.
- **HU-REV-04:** Como revisor autorizado, quero aprovar questões revisadas, para permitir sua inclusão no banco de questões.
- **HU-REV-05:** Como revisor autorizado, quero rejeitar questões inadequadas, para impedir que conteúdos incorretos sejam disponibilizados.
- **HU-REV-06:** Como revisor autorizado, quero consultar o status de revisão de cada questão, para acompanhar as pendências de validação.

## 3. Coordenador pedagógico

**Objetivo:** Acompanhar o desempenho das turmas e orientar intervenções pedagógicas.

- **HU-COORD-01:** Como coordenador pedagógico, quero visualizar os resultados das turmas, para identificar dificuldades de aprendizagem.
- **HU-COORD-02:** Como coordenador pedagógico, quero analisar o desempenho por habilidade e descritor, para identificar conteúdos que precisam ser reforçados.
- **HU-COORD-03:** Como coordenador pedagógico, quero comparar os resultados entre turmas, para identificar diferenças de desempenho.
- **HU-COORD-04:** Como coordenador pedagógico, quero acompanhar a evolução dos estudantes ao longo do tempo, para avaliar o progresso da aprendizagem.
- **HU-COORD-05:** Como coordenador pedagógico, quero identificar habilidades com baixo desempenho, para planejar intervenções pedagógicas.
- **HU-COORD-06:** Como coordenador pedagógico, quero consultar relatórios de desempenho, para apoiar o planejamento pedagógico da instituição.

## 4. Gestor escolar

**Objetivo:** Acompanhar os resultados gerais da escola e comparar o desempenho das turmas e dos anos escolares.

- **HU-GEST-01:** Como gestor escolar, quero visualizar os resultados consolidados da escola, para acompanhar o desempenho geral dos estudantes.
- **HU-GEST-02:** Como gestor escolar, quero comparar os resultados entre turmas, para identificar aquelas que necessitam de maior atenção.
- **HU-GEST-03:** Como gestor escolar, quero comparar os resultados entre anos escolares, para analisar a evolução da aprendizagem.
- **HU-GEST-04:** Como gestor escolar, quero visualizar indicadores de desempenho, para avaliar os resultados educacionais da instituição.
- **HU-GEST-05:** Como gestor escolar, quero consultar relatórios consolidados, para apoiar a tomada de decisões administrativas e pedagógicas.
- **HU-GEST-06:** Como gestor escolar, quero acompanhar a evolução dos indicadores ao longo do tempo, para avaliar a efetividade das ações educacionais.

## 5. Gestor de rede de ensino

**Objetivo:** Monitorar e comparar o desempenho das escolas que fazem parte da rede de ensino.

- **HU-REDE-01:** Como gestor de rede de ensino, quero visualizar os resultados consolidados das escolas da rede, para acompanhar o desempenho geral da rede.
- **HU-REDE-02:** Como gestor de rede de ensino, quero comparar os resultados entre diferentes escolas, para identificar diferenças de desempenho.
- **HU-REDE-03:** Como gestor de rede de ensino, quero analisar os resultados por ano escolar, para acompanhar a aprendizagem nos diferentes níveis de ensino.
- **HU-REDE-04:** Como gestor de rede de ensino, quero identificar escolas com dificuldades de aprendizagem, para direcionar recursos e ações de apoio.
- **HU-REDE-05:** Como gestor de rede de ensino, quero consultar indicadores educacionais consolidados, para apoiar o planejamento das políticas pedagógicas da rede.
- **HU-REDE-06:** Como gestor de rede de ensino, quero comparar os resultados ao longo dos anos, para avaliar a evolução do desempenho educacional das escolas.

## 6. Administrador

**Objetivo:** Gerenciar os cadastros, os acessos e a estrutura organizacional do sistema Mentary.

- **HU-ADM-01:** Como administrador, quero cadastrar e gerenciar instituições de ensino, para manter a estrutura institucional do sistema atualizada.
- **HU-ADM-02:** Como administrador, quero cadastrar e gerenciar turmas, para organizar os estudantes e professores por turma.
- **HU-ADM-03:** Como administrador, quero cadastrar e gerenciar professores, para controlar os profissionais que utilizam o sistema.
- **HU-ADM-04:** Como administrador, quero cadastrar e gerenciar estudantes, para manter os registros dos alunos atualizados.
- **HU-ADM-05:** Como administrador, quero criar e gerenciar usuários e seus perfis de acesso, para garantir que cada usuário tenha as permissões adequadas.
- **HU-ADM-06:** Como administrador, quero cadastrar e gerenciar outros administradores, para organizar a administração do sistema.
- **HU-ADM-07:** Como administrador, quero gerenciar as modalidades de ensino, para manter a organização dos níveis e das modalidades educacionais atendidas.
- **HU-ADM-08:** Como administrador, quero editar ou desativar cadastros quando necessário, para manter a integridade das informações do sistema.

## 7. Estudante

**Objetivo:** Acompanhar o próprio desempenho e identificar oportunidades de melhoria na aprendizagem.

- **HU-EST-01:** Como estudante, quero visualizar os resultados das minhas avaliações, para conhecer meu desempenho acadêmico.
- **HU-EST-02:** Como estudante, quero consultar meu histórico de avaliações, para acompanhar minha evolução ao longo do tempo.
- **HU-EST-03:** Como estudante, quero visualizar meu desempenho por habilidade e descritor, para identificar os conteúdos em que preciso melhorar.
- **HU-EST-04:** Como estudante, quero identificar minhas dificuldades de aprendizagem, para direcionar meus estudos.
- **HU-EST-05:** Como estudante, quero acompanhar minha evolução acadêmica, para verificar meu progresso nos estudos.
- **HU-EST-06:** Como estudante, quero consultar as avaliações disponibilizadas para minha turma, para conhecer as atividades avaliativas atribuídas a mim.
